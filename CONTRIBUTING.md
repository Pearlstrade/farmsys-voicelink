# Contribution checklist

- [ ] CALL-E is actually invoked at runtime in live mode.
- [ ] Demo mode never places a real call.
- [ ] AI disclosure is present.
- [ ] Consent/opt-out behavior tested.
- [ ] Credentials are environment variables only.
- [ ] Phone numbers are not hard-coded in production code.
- [ ] Human confirmation is required before commercial commitment.
- [ ] `pytest` passes.
- [ ] README includes setup, safety, and CALL-E usage.
- [ ] Demo video is under three minutes.
